> **Epistemic Discipline:** Every entry below distinguishes `[Official Doc]` (verified from upstream GitHub/Hugging Face/NVIDIA/Qwen docs), `[Observed Empirical]` (measured on real CPU hardware in this repo), and `[Unmeasured / Unknown]`. ## 1. Candidate Families Evaluated

| :--- | :--- | :---: | :--- | :--- | :---: | :---: | :--- |
| **`sherpa-onnx` (`v2.0.2`)** | C++ / ONNX Runtime (`1.28.2`), zero Python | `Apache-2.0` | **Native token/word for NeMo CTC & TDT**; segment-only for Whisper | **NeMo FastConformer CTC/TDT, Whisper, Qwen3-ASR, SenseVoice, Moonshine, Silero VAD** | **BEST** (1 single ~26 MB native binary runs all architectures!) | WASM builds exist, or pair with `onnxruntime-web` | Whisper in `sherpa-onnx` lacks DTW word timestamps (must use CTC/TDT or external aligner). |

## 4. Shortlist Selected for Real Empirical CPU Benchmarking

From the 14 candidate families audited above, we immediately disqualified legally blocked (`MMS`, `SeamlessM4T`, `hezarai/whisper-small-fa`) and non-Persian (`Parakeet v2/v3`, `SenseVoiceSmall`, `Moonshine`) models, and executed real offline CPU benchmarks on the **5 representative open-source ONNX models** covering every viable architectural paradigm:

1. `Reza2kn/Shenava-Rizeh v1.0` (`NeMo FastConformer CTC INT8`, `Apache-2.0`) — ultra-lightweight Persian CTC with native word timestamps.
2. `openai/whisper-large-v3-turbo-int8` (`MIT`) — best CPU-viable multilingual Encoder-Decoder.
3. `openai/whisper-base-fp32` (`MIT`) — lightweight multilingual FP32 baseline.
4. `openai/whisper-base-int8` (`MIT`) — FP32-vs-INT8 quantization ablation on small Whisper.
5. `Qwen/Qwen3-ASR-0.6B-int8` (`Apache-2.0`) — modern LLM-decoder multilingual ASR contender.
