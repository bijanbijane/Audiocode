## 2. Circular Dependencies & Structural Health
- `npx --yes madge --circular --extensions ts,tsx src/ packages/` measured **0 circular dependencies** across **318** inspected source files (`[Observed Fact]`).
- Full codebase baseline prior to `M-P0-01`:
  - `npx vitest run`: **13 / 13 files, 75 / 75 tests PASSED**.
  - `npx --yes tsx --test $(find src packages backend -name '*.test.ts' | sort)`: **248 / 250 PASSED, 2 FAILED** (`PersianProsodicPunctuationRestorer.test.ts:7`, `EditQualityVsModelQualityEvaluator.test.ts:6`).
  - `python3 -m py_compile`: **3 / 3 scripts PASSED**.

## 3. Top Structural Gaps Requiring Governance Control
1. **Unify Backend Authority:** Deprecate/archive or decouple dormant `backend/src/server.ts` + `backend/db/` from active runtime `/server.ts` + `/platform/migrations/` so Dockerfiles, migrations, and CI reflect one source of truth (addressed in ADR-001 & ADR-002).
2. **Eliminate Unverified Test Blind Spots:** Wire one root command executing *both* `vitest run` and all `*.test.ts` suites so partial phase test runs never mask regressions in core math/text modules (`M-P0-01`).
3. **Separate Deterministic Local Capability vs Neural Weight Inference:** Public docs, API metadata, and capability matrices must clearly mark when transcription uses acoustic heuristics + corpus normalization versus loaded neural weights (ADR-003).
4. **Harden Missing External Dependency Gates:** Any feature requiring PostgreSQL (`DATABASE_URL`), GPU Worker (`ASR_GPU_WORKER_URL`), Neural MT (`GEMINI_API_KEY`), or `cargo` must fail closed cleanly with deterministic capability codes (`503 PROVIDER_UNAVAILABLE` / `BLOCKED_BY_EXTERNAL_DEPENDENCY`).
